# 管道监测系统（PipeMonitor）

## 项目简介

本项目用于实现一套基于 **PC + RS485/Modbus RTU 传感器网络** 的管道参数监测系统。当前接入的传感器包括：

- **一体式压力温度传感器**（Modbus 从站）
- **超声波流量计**（Modbus 从站）

现阶段系统以 **上位机（Windows C# 程序）作为 Modbus 485 主机**，负责轮询读取两个从站设备的数据，并在软件界面中显示压力、温度、流量等关键参数。

后续计划在系统中加入 **单片机节点**，形成更完整的分层式架构：

- 一条总线由 **单片机作为主机**，负责采集底层传感器数据
- 另一条总线由 **PC 作为主机**，负责与单片机通信、显示数据、进行参数配置和上位管理

该项目适合用于：

- 管道流量/压力/温度联合监测
- 工业现场 485 设备联网采集
- Modbus RTU 通信调试与上位机开发
- 后续嵌入式采集系统扩展验证

## 分层说明

### 1. 传感器层

负责现场物理量采集，包括：

- 压力
- 温度
- 流量

### 2. 控制层（后续）

由单片机承担以下职责：

- 轮询底层传感器
- 做基础数据处理与缓存
- 统一对上位机提供数据接口
- 预留控制逻辑、告警联动和本地显示功能

### 3. 上位机层

由 Windows C# 程序承担以下职责：

- 串口通信
- Modbus 主站轮询
- 数据解析与显示
- 参数配置
- 调试信息输出
- 后续数据存储、曲线和告警扩展

## 压力温度传感器说明（已确认部分）

根据现有说明书，压力温度变送控制器具备以下特性：

- 支持 RS485 通讯
- 支持 Modbus RTU
- 支持波特率配置
- 支持设备地址配置
- 可读取压力与温度相关数据
- 默认供电为 DC24V
- 说明书给出的串口格式为 9600, N, 8, 1 兼容模式，且支持多个波特率选项

项目实现时，应重点关注：

- 仪表地址设置
- 波特率一致性
- 压力寄存器读取
- 温度寄存器读取
- 小数点位解释

## 使用流程（当前阶段）

1. 连接 RS485 总线与传感器
2. 确认两个设备供电正常
3. 确认设备地址、波特率、串口参数一致
4. 打开上位机软件并选择对应串口
5. 建立连接后轮询读取数据
6. 在界面中查看压力、温度、流量结果
